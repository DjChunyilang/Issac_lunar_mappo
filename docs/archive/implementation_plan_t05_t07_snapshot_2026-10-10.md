## T06：Torch批量MPPI基础

### 调度、模型与限制

每个(env_id,agent_id)独立状态，共享无状态Torch内核。按设备／精度／参数分组后恢复顺序；NMPC逐实例，MPPI真实批量。仅时间／迭代／内存分块循环，实例和样本向量化。保留单条plan。

控制与实际速度[B,K,15,2]，状态[B,K,16,3]，代价和有效标记[B,K]，热启动均值[B,15,2]。网格0.2 s、15步不变。默认CPU，显式CUDA不可用提前报错，不静默降级。

基础只在平坦场景验收，使用中点差速模型。控制是轮速等效v/omega，实际速度另存。限值为线速±1.15、角速±2.4、轮半径0.098、轮距0.376、轮速±18；首步从上一实际下发控制开始，步间增量≤0.3/0.6。先限制幅值和轮速，再沿上一控制至目标的线段步进同时满足变化率，整条序列复核。

HOLD使用共享限幅停车，不采样重新移动；移动阶段可返回显式刹车反馈。安全接口直通projection_disabled，不作为T08安全投影。

### 算法与参数

原始采样Z=U+epsilon，epsilon为协方差Sigma的零均值高斯；实际控制C=g(Z,previous_control)。采用[Williams原始方法](https://arxiv.org/abs/1707.02342)的重要性修正：

$$
S_k=J_k+\tau\sum_t U_t^\top\Sigma^{-1}\epsilon_{k,t}
$$

$$
w_k=\frac{\exp(-(S_k-S_{\min})/\tau)}{\sum_j\exp(-(S_j-S_{\min})/\tau)},\qquad U_t\leftarrow U_t+\sum_k w_k\epsilon_{k,t}.
$$

修正使用原始扰动，不替换为裁剪差。数值无效样本计算权重前排除，全无效不softmax并回退。规划代价独立于团队学习奖励。

| 参数 | 默认 |
| --- | --- |
| 时域 | 3 s，15×0.2 |
| 样本 | 512；候选512/1024/2048 |
| CPU测试／集成样本 | 64／128，产物明确覆盖 |
| 每次优化 | 2轮 |
| 噪声标准差 | v=0.35，omega=0.7 |
| 温度 | 1，与PPO gamma/lambda分开 |
| 精度 | float32，解析参考float64 |
| 种子 | 默认23；重复性23/31/47 |
| CPU墙钟截止 | 默认关闭；记录耗时，超时分支单独测试 |

目标逐节点二维距离平方权重2、终端12；控制0.05v²+0.03omega²，变化0.5Δv²+0.2Δomega²，倒车0.2min(v,0)²。显式航向仅在输入提供时参与。阶段累加，终端单独加入，T02奖励不改。

### 状态、输出与回退

初次用固定目标引导控制初始化；后续按实际经过步数移位、停车尾段，从当前位姿重新预测。批次切分不reset，异步reset仅对应环境；实例独立随机状态保证换序／稀疏批／其他环境reset不改变采样。

快照保存均值、上一轨迹、请求及随机状态，张量导出CPU，无求解器对象。同设备／同版本可重复恢复；跨CPU/CUDA热状态拒绝，可另起冷启动run。

选择顺序：更新序列完整复核 → 本轮最低代价可行样本 → 带停车尾段可行前缀 → 复核移位旧计划 → 限幅刹车valid=false。均值必须重新预测／复核；过期直接刹车。total_cost为最终轨迹实际代价，不可靠则None；单独记分量、有效样本比例、权重有效样本数、候选拒绝和回退源。

## T07：局部地形与邻车

### 地形查询与代价

TerrainView提供版本化独立只读样本快照，仅位置、五维特征、时间及支持半径。不得暴露全局DEM、core、Oracle或其他私有记忆。Torch带掩码点集分块最近邻，查询块256，不分配完整[B,K,N,M]。保留支持半径／未知／直接观测；空／覆盖外未知，不插值跨空洞。等距属性冲突保守处理，输出再经CPU查询复核。

当前粗糙度无有效观测，不构造粗糙度代价；可通行度是现有风险代理。地形速度缩放复用已有解析模型、下限0.25。

软风险权重2，项为(slope/0.8)²+((1-traversability)/0.75)²；未知诊断每节点20，完整未知样本不可有效执行。硬边界：known、traversability≥0.25、slope≤0.8，控制段9点复核。关闭软代价不关闭硬边界；地形动力学独立开关。

距现有安全半径0.2 m范围内平方软风险，权重8；硬复核复用段插值及相对位移补偿。覆盖交叉／迎面／停稳／换槽／稀疏／过期。关闭软项保留硬碰撞检查。总成本按原计划七项记录，重要性修正另记。
