# 多月球车自组织集合项目本周工作汇总

时间：2026年8月17日至2026年8月21日

## 一、总体工作概览

本周围绕上周提出的“团队奖励难以区分单车贡献”问题，完成了两种信用分配方法的实现与训练前验证。同时，将完整任务拆分为“共同平地发现与确认”和“安全到达并集合”两个阶段分别检查，并通过一组受控长训进一步判断当前瓶颈。

本周仍未得到满足全部验收条件的策略，但问题范围已经明显缩小：现阶段没有证据支持继续扩大信用分配模型；在共同集合区域已经明确的情况下，车辆基本能够完成集合，主要不足转为复杂地形和远距离场景中的末段避碰与协同。

## 二、上周遗留问题及本周尝试

### 1. 上周遗留问题

当前训练以四辆车的整体表现作为共同奖励。当少数车辆发生碰撞或选择了不合理路径时，其影响会混入整个团队的学习信号，使系统难以准确判断每辆车的具体贡献。这可能导致正确动作与错误动作得到相近评价，降低学习效率。

### 2. 尝试一：DAE差分优势方法

本周首先参考Li、Xie和Lu在ICML 2022提出的Difference Advantage Estimation（DAE）方法。[1] 这一选择也受到COMA反事实信用思想的支持：保持其他车辆的动作不变，只改变其中一辆车的动作，再比较团队结果的变化。[2]

选择DAE的原因是，它可以保留现有MAPPO主体，只调整训练阶段对单车贡献的估计方式；实际执行时，每辆车仍只使用本车观测和允许的通信信息，因此不改变去中心化要求。

DAE的基本原理可以概括为：先估计“该车辆实际动作产生的团队结果”，再估计“该车辆改选其他动作时的平均结果”，两者之差作为该车辆更有针对性的学习信号。

为避免直接开展高成本长训，本周先在固定场景中枚举替代动作，检验该估计是否足够可靠。结果表明，模型能够粗略判断部分动作的相对好坏，但无法准确估计替代动作的平均结果；其误差约为正常奖励波动的2倍。因此，DAE没有进入正式训练阶段。

### 3. 尝试二：更保守的奖励拆分方法

在DAE未通过后，本周参考Partial Reward Decoupling（PRD）研究，尝试从每辆车的学习信号中移除与其当前动作无关的部分奖励。[3] 与DAE相比，这一方法不再预测替代动作的结果，而是直接依据现有奖励组成进行拆分，目的在于以更低风险减少团队奖励中的无关干扰。

该方法保持了团队总奖励和主要学习方向不变，但实际能够移除的干扰只占原学习信号的约2%至3%，学习波动最多降低约7%，未达到预先设定的有效门限。因此，该方法同样没有进入正式训练。

### 4. 尝试三：将共同选址与安全到达分开验证

前两项尝试说明，仅从团队奖励中区分单车贡献，并不能充分解释当前训练困难。完整任务同时要求车辆找到同一块平地，并安全行驶到该区域；如果直接训练整个任务，很难判断失败发生在哪一环节。

因此，本周参考目标条件策略的研究思路，将任务拆分为两段：第一段负责决定“共同去哪里”，第二段只负责“如何安全到达”。[4] 这种拆分不是增加中央控制器，而是先分别验证两个必要能力，再将其重新连接。

### 5. 尝试四：主动发现并确认共同平地

初始检查发现，仅依靠车辆起点附近的一次局部观测，全部场景中只有约40.80%能够直接发现可供四辆车集合的平地，狭窄地形中的覆盖率接近零。因此，即使低层控制策略正确，车辆也可能根本没有获得足够信息来选择共同目标。

本周参考多机器人主动信息采集和分布式探索研究，让车辆在移动过程中保存已经发现的平地候选、分工搜索未观测区域，并在通信恢复后交换候选信息。[5][6] 同时借鉴去中心化公共知识的思想，只有四辆车都能确认同一区域时才完成提交，避免各车选择不同集合点。[7]

第一次验证还发现，原狭窄地形中布置的100个陨石坑几乎清空了内部可行平地，使部分场景在任务定义上不可完成。随后在保留墙体、通道和坡度难度的前提下，将陨石坑数量调整为30个，不向车辆提供平地坐标。

修正后，在六类共1152个固定场景中，有效共同区域确认率达到97.40%至100%，错误确认率为0。该结果只验证到“共同区域已经确认”，车辆在确认后尚未继续执行最终集合。

### 6. 尝试五：共同区域已知时的受控长训

为单独检查第二段能力，本周进行了一次受控长训：训练时直接给出共同集合区域，只考察车辆能否安全到达并稳定集合。该实验完成约7860万次环境交互。

在近距离开阔场景中，策略一度达到98.44%的成功率和1.30%的碰撞率，说明基本集合能力能够学会。但扩展到复杂地形和远距离通信后，最终成功率为86.98%，碰撞率为12.50%，超时率为0.52%，未满足严格验收要求。主要失败由“无法集合”转为“接近集合区域时发生碰撞”。

## 三、最终效果、结论与下一步

| 验证方向 | 最终效果 | 结论 |
| --- | --- | --- |
| DAE信用分配 | 替代动作的平均结果估计误差过大 | 当前形式不进入训练 |
| 保守奖励拆分 | 只能去除约2%至3%的无关信号 | 改善幅度不足 |
| 共同平地发现与确认 | 六类场景确认率97.40%至100%，错误确认率为0 | 前半段基本可行，尚非最终集合成功 |
| 已知共同区域下的长训 | 成功率86.98%，碰撞率12.50%，超时率0.52% | 基本集合可学，复杂场景协同未通过 |

本周没有得到满足全部标准的最终策略，但已经排除了两条收益不足的信用分配路线，并确认共同平地发现与团队确认可以继续使用。当前最需要解决的问题，是车辆在复杂地形中接近同一集合区域时，无法充分判断其他车辆接下来准备如何运动。

下一步计划如下：

1. 暂停扩展DAE和奖励拆分方法，保留本周结果作为排除依据，不降低验证门限。
2. 将目前重复发送全部候选信息的方式改为只发送新增或变化的信息，降低通信负担。
3. 参考MADER共享已承诺短时轨迹的思想，在近距离通信中传递车辆已经确定的短时运动意图，使其他车辆能够提前判断让行关系。[8] 这里只迁移信息表达方式，不加入论文中的中央优化或Actor后安全修正。
4. 以独立的去中心化集合控制器验证复杂地形中的末段避碰，再接回已经通过的共同平地发现与确认流程。
5. 只有完整闭环在六类场景和多个训练种子中均通过严格评测后，才进入物理仿真验证。
