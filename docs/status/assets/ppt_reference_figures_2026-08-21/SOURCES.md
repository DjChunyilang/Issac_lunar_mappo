## 使用边界

- 论文图仅用于学术汇报，页面中应保留作者、年份、论文名称和图号。
- 本目录只裁去论文图周围无关正文，没有改动图内坐标、图例或数据。
- NASA图片使用前应核对原页面署名。
- 项目图和GIF只能作为项目诊断与行为展示，不能替代严格评测文件。
