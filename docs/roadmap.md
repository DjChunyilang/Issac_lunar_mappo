# 路线图

## 当前基线：exp156 N1

`exp156`的N0/N1完整训练均落入success近零、timeout超过92%的地板区。N2完整训练已经取消；修复路径采样连续性后仅完成CUDA smoke。当前暂用N1多尺度CNN作为接口基线，但其0/6 strict且checkpoint仍为 `candidate`。

## 当前执行点

工程准入已完成：专项测试、CPU smoke、三种Actor的CUDA 256环境smoke、12场景原语覆盖审计和1152场景manifest均已通过或生成。N2 smoke只证明工程可训练，不恢复完整消融。`exp157` H0已完成：通信图虽全连通，但只有40.97%的固定场景在reset时至少一车看到共同站点区域。

下一步执行顺序为：

1. 保留N0/N1既有结果，不再重新训练；
2. H0站点信息可辨识性和末段联合原语可行性审计已完成；
3. 启动N1 CNN的H1“共同可行站点belief已知”39.3M有界对照；
4. 只有H0/H1表明共同选址协议是主瓶颈，才决定是否实现D-STC；
5. D-STC若获准，先实现确定性候选关联与commit，不同时加入GRU、GNN、DAE或学习消息。

## 停止条件

- N2不得重新启动完整训练；
- N1只作临时接口基线，不得标记为架构胜者或推荐checkpoint；
- 场景复现哈希不一致时拒绝评测，不能退化为不同seed的非配对比较；
- N0/N1正式分层均失败，因此不启动seed31/47；
- 标准MAPPO失败时先做冻结因果审计，不直接叠加DAE、GRU或GNN。

## 正式通过后

三个训练种子全部通过后才执行：

1. 生成正式评测动画；
2. 进入Isaac/PhysX闭环验证；
3. 将获胜Actor和差速接口写入 `docs/technical_design.md`；
4. 判断是否还有证据支持下一轮信用、记忆或通信结构研究。

## 保持冻结

- BC、教师策略和历史checkpoint迁移；
