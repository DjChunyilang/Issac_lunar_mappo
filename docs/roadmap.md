# 研究路线图

更新：2026-10-22。当前执行顺序按[实施计划](implementation_plan.md)，旧 T11 及后续阶段的编号不再决定本轮训练准入；原路线全文见[快照](archive/formal_training_transition_2026-10-22/docs/roadmap.md)。

1. **正式训练主方案。** 在真实 NPB 地形与坑石增强、合法局部感知／通信下训练 A1＋MPPI，观察完整集合任务表现；针对实际失败修复已有组件。
2. **形成可用基准。** 结合完整回合行为、初始化对照及既定独立评估判断结果价值，冻结可复现的配置、源码与 checkpoint。弱结果如实报告，不用额外门槛阻塞主训练。
3. **恢复消融研究。** 基准形成后，再安排动作表示、规划器、感知／通信、奖励和其他机制对照；先确定具体问题，再选择矩阵与预算，不自动补跑所有历史组合。
4. **扩大验证。** 对候选开展额外种子、独立地理区域和完整系统评测，报告泛化、失败、性能和资源成本。
5. **Isaac／PhysX 验证。** 单独核验真实执行模型、足迹与物理接触差异，不能由 Proxy 成功推定。

**T15 贯穿上述流程。** 当前入口、配置身份、依赖、恢复边界和产物持续维护；拆分及迁移只随实际需要实施，不另开一轮全面重构作为训练前置条件。

地图继续沿用[真实 DEM＋有来源的坑石增强](architecture/lunar_map_mainline.md)。训练／评估地理隔离和版本身份保留，同一地理窗口的增强不当作独立地域样本。历史未完成矩阵保持原状态，参考实验仅在后续研究需要时恢复。
