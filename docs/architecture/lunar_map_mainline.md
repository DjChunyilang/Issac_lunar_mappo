# 月面地图主线：真实 DEM 与 NASA 模型增强

状态：**2026-09-25 用户确认的地图部分后续主线**。本页统一定义地图路线与边界；
具体结果见[验收记录](../experiments/nasa_sfd_v2_2026-09-24.md)，复现命令见

## 已确定的处理链

**真实轨道 DEM → 地理裁剪与缓冲 → 插值/重采样的仿真表示 → NASA 模型坑石增强 →
分层 ScenePack → 环境查询、后续训练与评估。**

真实 DEM 提供区域地形起伏；插值形成连续的数值表示；轨道产品未解析的坑石以
有明确模型依据的假设层补充。主线目标是得到可用于本项目仿真的真实数据派生地图，
而非让真实数据满足旧纯随机地图的固定尺寸或平坦度分布。

| 数据层 | 当前实现 | 解释边界 |
| --- | --- | --- |
| 真实产品层 | NASA LOLA NPB 高程、采样数量、总高程误差；源文件及哈希保留 | 官方产品本身包含重建/插值，不是每格独立实测 |
| 任务表示层 | 保持物理尺度与可逆坐标；严格有效支撑的双线性重采样 | 加密网格不增加测量精度；缺失值不补成平地 |
| 假设增强层 | NASA Ames synthterrain 的 VIPER 大小—频率公式与静态坑石关联，`nasa_sfd_v2` | 未在 NPB 亚米至米尺度标定；分布依据与形状假设分开记录 |
| 运行时地图 | 不可变 `lunar_training_terrain_v2` 场景包，共享 CPU/GPU 查询缓存 | 环境地形真值与 Actor 信息权限分开，旧 checkpoint 不静默复用 |

增强固定参考 `synthterrain` 提交 `e10ba36e9aa5b923bc7e6746ef089859af9ccaf8`。
大小—频率控制生成数量和直径，岩石位置使用背景与坑关联概率各 50%；坑龄/侵蚀
本轮关闭。坑形仍为既有连续多项式，岩石为半椭球高度包络。它是公开模型的适配，
不是 NASA 完整生成器、真实岩石网格或轮地接触模型的复现。

## 当前数据规模与完成范围

NPB 原始产品三层均为 4000×4000、5 米格距，覆盖同一 **20×20 千米**区域。
高程、采样数、误差 GeoTIFF 各约 64.03 MB，合计 **192.10 MB**（183.20 MiB）。
这是当前已下载的 NPB 产品，不是 NASA 全月数据总量。约 98.08% 的像元无落入该格
的直接激光回波，不能把有效高程像元数当成独立观测数。

已验收样例取母图 `[480,2480,40,40]` 原生窗口：200×200 米、1600 个原生像元，
另读周边缓冲。0.1 米处理网格有 2000×2000 个像元；5 米生成缓冲在最终输出时裁掉。
已生成 1 张基础图与种子 23/24/25 各两张增强图，共 7 张，全部属于同一个 NPB
开发区域，**不是七个独立真实地点或正式训练/测试集**。

当前诊断范围：坑直径 0.8–2 米、石直径 0.6–1.2 米；分形残差关闭。200 米场地、
0.1 米网格、直径上下限和现有几何比值均是本轮配置，不作为未来地图的固定科学约束。

验收已完成：36 项地形测试，四张地图各 32 GPU 环境×32 步无学习检查，CPU/GPU
查询一致性，以及 23 组 PNG/PDF 图。单图运行缓存约 122 MiB，GPU 分配峰值约
179 MiB。正式任务成功、GPU NMPC 全面性能、接触物理与地理泛化未据此验收。

## 后续工作顺序

1. **扩展真实地理覆盖。** 从 NPB 母图建立多个有坐标和来源记录的窗口；按需要补充
   其他 NASA 区域。先核查覆盖、重复产品及处理关系，再决定窗口尺寸和地理划分。
   不将已查看并用于开发的 NPB 样例改称未见测试区。
2. **形成训练与评估地图库。** 先隔离地理区域，再生成裁剪和种子增强；同地点的
   重采样、重叠裁剪与增强版本继承同组。NPB 内的空间划分只能支持区域内评估，
   跨区域泛化需要额外独立区域。保留原始地形分布及失败场景。
3. **验证任务和执行链适配。** 依据真实地形尺度与车辆/任务要求确定行驶距离、时限、
   感知和控制范围；继续使用离线生成和共享查询。资源不足时先调整缓存与并行度，
   不缩放真实几何、压平地形或减少坑石密度来迎合旧判据。
4. **冻结比较协议，再安排训练。** 配对比较真实底图、底图加坑、底图加坑石；保持
   算法、车辆、信息条件一致，先辨别数据与增强的影响。训练预算依据实测吞吐量提出；
   正式训练仍需后续明确恢复。区域标定与更精细几何作为可追踪的改进项，不把它们
   误写成当前已实现或仿真地图生成的绝对前置条件。

NASA 工程模型不因本次路线确认就成为 NPB 实测真值。若以后用观测校准参数，仅使用
开发区域；无依据的细节继续标注为假设。0.75 米半径、0.18 米高差、0.25 坡度等
旧平坦度判据不用于筛选原始地图，车辆安全要求也不能由地图统计直接反推。
