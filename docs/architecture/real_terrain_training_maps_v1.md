## 目标与当前差距

目标是获取真实月面地形数据，以真实高程为依据，通过裁剪、插值、重采样和适当的缺测处理生成可用于本项目训练的地图，逐步替换缺少真实地形依据的纯随机地图。

目前已有LUPEX六区1米DTM、配准与质量审计、地理分组，以及原生/双线性高度查询。但尚未形成批量生成的训练地图库，也尚未接入正式训练环境。下一步应完成这两项；独立点运动诊断不等于训练环境接入。

真实数据可以作为连续仿真地面的采样依据。原始采样比仿真网格稀疏时，允许插值生成更密的网格用于训练。生成网格间距与原始数据间距分别记录即可；不能将插值后的网格密度表述为新增实测精度。近地面数据和车辆真实安全验证属于进一步提高物理可信度的工作，不是当前地图生成的前置门槛。

## 实施顺序与交付

### 1. 以现有真实数据制作第一批训练地图

优先使用已下载的LUPEX，不继续扩大为泛化的数据精度调查。只有现有数据在覆盖、格式或实际生成效果上确实不足时，再定向补充数据。

- 输入完整DTM、坐标、原始缺测掩码及来源标识；先继承已有地理/来源分组，再在每组内裁剪。
- 裁剪范围和目标网格间距均可配置；根据真实覆盖和训练环境的查询、运动、内存需要选择示例，不预设固定25米场地，也不因相关长度未知而禁止裁剪。
- 保留原始水平距离和相对高差。可平移局部坐标及高程零点，不通过水平压缩、压平或高差缩放使地形满足旧阈值。
- 完整规则网格的初版加密采用双线性插值；保留原生视图作为对照。若后续使用不规则高程点，再增加适合散点的插值路径，不必把现有规则DTM人为降采样成散点。
- 缺测补全单独处理，不能与有效像元间重采样混为一谈。先支持完整数据块；再对局部孔洞制定可配置的范围、距离与支持规则。大块无依据区域保留缺测，不默认跨越整片阴影补平。
- 输出原始支持、插值/补全和剩余无效掩码，以及算法、参数、来源、源区域和物理尺度。

**交付**：地图生成脚本、生成配置、第一批真实数据派生地图、原始/生成地形对比图、地图清单。地图可采用高度场及元数据供现有环境查询；是否再导出网格模型由接入接口决定。

### 2. 验证生成结果并接入训练环境

验证关注地图是否正确表达输入数据及是否能供环境运行：原采样位置高度一致性、坐标方向、尺度保持、边界连续性、缺测传播、插值引入的梯度变化。补洞参数需要测试时，在开发区域遮蔽已有数据，按实际孔洞形状做恢复检查；这检验插值方法，不宣称恢复了原图没有观测的细节。

将地形来源接入当前选用的训练环境，使reset可选地图/裁剪，运动与地形指标查询使用同一表面，支持地图尺寸与网格间距变化。明确接通观测、局部地图和控制查询；仅提供独立诊断接口还不算完成。

工程上先保持所选算法与研究任务主线，检查数据源替换造成的具体适配需求。确需改变场地、时间尺度或特征语义时记录版本及原因，不把旧参数强加给地图，也不为导入地图先重做整套车辆与作业研究。新特征/地图语义不兼容时，明确处理旧checkpoint，避免静默复用。

**交付**：训练环境的数据源配置、地图加载/reset/执行回归、无学习运行记录及吞吐量测量。地图给仿真使用不自动意味着Actor获得全图。

### 3. 在真实数据派生地图上训练与评估

接入验证后提出训练配置和预算，按当前训练暂停约束单独安排启动。训练可以从开发区随机抽取多个裁剪，重采样版本和同地点变换全部继承原组。相关裁剪是合法训练样本，但不能被统计为独立地理样本；训练与测试不得包含同地点的裁剪或派生版本。

首轮目标是验证本项目能在真实数据派生地图上训练。先完成这一链路，再比较纯随机、真实数据派生及可选的统计校准合成地形；合成参数拟合不是先决条件。公平比较时固定算法、任务和信息条件，记录必要的配置差异。

**交付**：明确使用这些地图的训练配置、区域隔离评估配置，以及随后实际执行的训练/评估记录。当前只有计划更新，没有生成新地图或启动新训练。

## 对已有成果和约束的处理

| 已有内容 | 当前用途 |
| --- | --- |
| 六区数据审计、坐标与校验和 | 直接复用为输入准备与来源追踪 |
| 敏感性与缺测图 | 辅助选择处理方法和记录生成区域，不作为阻止插值训练的理由 |
| 原生查询、分块缓存与特征版本 | 复用并扩展为生成地图的加载与运行时查询 |
| 四个来源关联组 | 保留跨训练/评估的隔离约束；12组合交叉验证不必全部跑完才允许首轮接入 |
| 相关长度尚有删失 | 限制独立样本量的解释，不限制训练中同一区域的裁剪抽样 |
| 车辆安全与近地面尺度缺口 | 记录为物理解释边界；不作为生成/接入训练地图的前置阻塞 |
| 统计校准合成与微地形增强 | 后续可选对照，优先级低于真实数据插值地图的直接使用 |

后续工作的验收点是“能从真实数据生成地图并由训练环境实际使用”，不再仅以扩大调研、增加审计指标或完善独立诊断接口作为完成。
