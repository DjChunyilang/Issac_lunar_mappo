# 真实月面数据优先：接口、约束与任务适配

本文保留2026-09-22的LUPEX原生数据接口、旧约束处置及科学解释边界。
2026-09-25地图后续主线已确定为[真实DEM与NASA模型增强](lunar_map_mainline.md)；
当前环境地图接口和结果见[NASA SFD验收](../experiments/nasa_sfd_v2_2026-09-24.md)。
下文的`lunar_scene_v1`是早期审计/查询接口，不等同于当前`lunar_training_terrain_v2`。
原撤回草案仅用于历史追溯，不再指引下一步执行。学习训练保持暂停。

## 依据与实现边界

地形事实来自数据产品、重建过程及误差分析；车辆能力和作业要求来自车辆与任务；工程参数服务于这两者。地图分布不能自行决定安全门槛。

本轮完成真实产品审计、区域隔离清单、原生栅格查询及无学习的点运动诊断接口。由于车辆接触尺度与作业依据尚缺，生产集合任务没有自动换用真实图，也没有重新定义安全、成功或奖励。新的点运动诊断不模拟车轮接触、滑移、碰撞、通信或光照。

## 旧约束处置清单

| 原约束 | 当前处置与依据 |
| --- | --- |
| 25×25米场地，0.75米半径、0.18米高差、坡度0.25 | 仅在旧任务中保留作历史对照；真实数据审计、分组、采样均不使用这些数值。生产替换需作业/车辆要求。 |
| 25米裁剪、50米上下文、每区64窗口 | 取消。分析完整产品及原ROI；多尺度指标从原生格距递增。本数据相关性尚有删失，基准目前保留完整区域。 |
| 按CR/GR/LP/MP名称分组 | 已替换为覆盖坐标、NAC影像ID、TC控制产品ID关联；形成4个保守组。 |
| 固定训练/验证/测试比例 | 已替换为4组嵌套留组法，12个train/validation/test组合；不按裁剪数计算独立样本量。 |
| 真实底图加合成细节作为主基准 | 主基准只含真实SfS产品及质量信息。假设增强层为空。 |
| 固定细节幅度、密度、0.5/1/2倍扫描 | 取消默认值；后续依开发区可解析统计或外部证据提案，无依据内容标为假设。 |
| 沿用旧观测通道与风险语义 | 新增`lunar_dtm_metrics_v1`；坡度、去趋势粗糙度、支持性和敏感性分开。旧五通道不自动接收新数据。 |
| 0.1米缓存与0.155米支持半径 | 新路径采用原生像元块LRU；查询密度不提升观测精度，指标尺度由原生像元数明确给出。 |
| 96秒时限、原初距与控制尺度 | 对数据审计不适用；新任务时限需距离、速度、停驻及通信需求共同确定。 |
| exp167唯一算法、90万交互 | 均不是新基准约束。exp167保留候选对照，预算待任务与吞吐量明确后再提。 |
| CPU与5 GiB为科学边界 | CPU仅为本次执行方式；查询缓存可配置。按区域依次分析，不缩放地形迎合算力。 |
| 来源追踪、可复现、地理隔离、公平比较 | 保留并实现；场景与划分包含版本及内容校验。 |

## 三层数据与坐标契约

1. **真实产品层**：原始ZIP不写入；解压产品设为只读，保存每个成员SHA256。DTM是影像与先验约束下的SfS重建，不称为直接接触测量。
2. **任务表示层**：`lunar_scene_v1`保存原始DTM/敏感性图引用、源校验和、局部原点及特征版本。当前为完整产品原生视图，未重采样。`native_patch()`可按整像元裁剪返回高程、无效掩码、敏感性、仿射变换和来源；不补洞、不重设比例。
3. **假设增强层**：通过`layers.json`单独声明，本轮没有生成内容；未来的微坑、石块和误差扰动不得覆盖前两层。

坐标为月球南极极射赤面投影，参考球半径1,737,400米。局部坐标等于投影坐标减场景原点，反向直接相加；经纬转换由源CRS执行。数组行向下，局部y沿投影北向上。投影米不完全等于表面测地距离；审计记录中心投影尺度因子，任务距离精化须使用该信息。现有GeoTIFF没有独立垂直CRS标签，绝对高程基准的进一步跨产品核验仍属缺口。

正射影像与DTM保持各自地理变换；本轮没有从影像生成Actor特征。不确定性按坐标最近邻查询，不按相同行列硬拼。像元相邻的数值不视为独立误差样本。

## 查询与尺度语义

实现位于`source/lunar_rover_tasks/lunar_rover_tasks/terrain_data/`：

| 字段/接口 | 语义 |
| --- | --- |
| `height_m`、`height_valid` | 最近原生像元或显式双线性查询；越界和缺测为NaN/false。双线性四个贡献像元必须全部有效。 |
| `slope_xy` | 指定方形物理基线内最小二乘平面梯度，单位m/m；y方向符号按投影北向。 |
| `detrended_rms_m` | 同一窗口去平面后的RMS，单位米；不再用坡度模长冒充粗糙度。 |
| `metrics_valid` | 完整窗口全部有效才计算；仅表示数据计算支持，不表示低风险。 |
| `height_sensitivity_m`、`support_max_sensitivity_m`、`error_valid` | 作者敏感性产品原值与窗口最大值/完整性；没有按独立高斯误差传播，没有输出置信概率。 |
| `native_spacing_xy_m`、`processing_spacing_xy_m` | 本轮均为原生1米；双线性查询也不改写原生支持精度。 |
| `baseline_xy_m`、`metric_center_local_xy_m` | `half_width=h`使用`(2h+1)²`原生样本，外侧样本中心间跨度`2h×格距`；指标中心吸附原生像元，显式报告位置。 |
| `effective_resolution_m` | `None`，作者定性约10米细节证据不被冒充确定的分辨率。 |
| `source_id`、`height_interpolation`、`schema` | 每条查询携带来源、插值方式和版本。 |
| `vehicle_safety` | 始终`unknown`；禁止据此生成停驻安全标签。 |

栅格按需读取，默认DTM和敏感性各16 MiB LRU，缓存块为工程参数；不将缓存采样点当成新增观测。全图审计逐区域处理，局部统计在当前区域内计算。全图相关长度是描述量，不是独立性证明。

## 信息权限与兼容路径

`TerrainProbeRuntime`区分内部地形、有限半径的局部查询及显式启用的轨道先验。局部请求连同整个分析窗口都必须处于允许半径内；默认拒绝远处轨道查询。它当前只是对轨道重建的访问权限模拟，没有验证为真实近地面传感器。`reset/step`的真值返回只用于诊断，不作为Actor观测。

旧`terrain_features.py`及旧checkpoint语义保持历史兼容。若把`lupex_dtm/raster_dtm`直接传给旧地形函数，会报错，避免因振幅默认为零而被误判成平地。新路径的`require_feature_schema()`拒绝缺少或不匹配的checkpoint特征版本；本轮没有加载或训练任何checkpoint。未来训练入口还必须把该校验纳入加载流程，不能只匹配张量维数。

## 数据驱动的任务参数提案

| 项目 | 当前可提出的候选或缺失条件 | 能否写入生产判据 |
| --- | --- | --- |
| 场地范围 | 原生区域约0.91–2.02 km宽、1.23–2.02 km高；先做完整区域地貌及可用数据分析。不能从中直接选出机器人任务距离。 | 暂不能 |
| 指标基线 | 2/4/8米保留作平滑与数值诊断；16/32米可作为区域地貌描述候选，必须同时报告完整支持覆盖率。 | 可用于描述，不能作为接触安全标准 |
| 初距/行驶距离/时限 | 等车辆最大/持续速度、作业路径、停驻与任务目的确定后，用距离和执行开销推算；不承袭96秒。 | 缺任务依据 |
| 候选区域面积/连通性 | 已统计数据有效域连通分量；这是数据覆盖连通性。满足车辆条件的连通域尚不能定义。 | 缺安全和车辆条件 |
| 车体足迹、爬坡、越障、停驻间距/保持 | 必须明确车型、轮距/轴距、载荷、姿态限制、作业允许误差；DTM无法提供亚米级接触验证。 | 缺车辆/作业依据 |
| 感知范围、地图精度 | 原生1米与未知有效分辨率已记录；近地面传感精度、遮挡、时效不能由轨道产品推得。 | 缺传感模型 |
| 通信条件/轨道先验 | 本轮仅实现权限分离；地图没有通信链路、带宽和遮挡时序依据。后续分别冻结“仅局部”“显式轨道先验”。 | 缺系统依据 |
| 控制/局部规划/观测 | exp167存在尺度与风险语义不匹配，应先在新契约下做执行诊断，再决定适配或替换；不默认继续使用原控制步长和局部范围。 | 待执行链与任务一起论证 |

上述待定项用于限定物理解释，不能用插值结果把它们写成已验证，也不阻止生成仿真训练地图。当前地图接入已推进到[主线说明](lunar_map_mainline.md)所记录阶段，后续方法比较遵循[比较协议](../experiments/lunar_terrain_comparison_protocol.md)。
