# 新地图任务适配方案

日期：2026-09-26。状态：用户接受适配建议，通信半径暂定24 m；本文记录后续实现与无学习验证的任务基线，尚未修改运行配置或实现、尚未验收。正式训练继续暂停。

地图来源遵循[地图主线](lunar_map_mainline.md)。当前200×200 m开发窗口不是正式训练/测试集；保持地理隔离与原始地形分布，不通过压平地图、减少坑石或删掉失败场景满足新判据。

## 已接受的参数与方向

| 项目 | 新方案 | 状态与解释 |
| --- | --- | --- |
| 通信半径 | **24 m** | 用户暂定；承接此前完整消息半径的讨论，替代18 m主候选；12 m保留历史对照。远距离稀疏消息的最大范围单独定义，不能把24 m直接写成已经实现的硬断联距离 |
| 出生半径 | 4–6、8–12、15–25 m三档 | 将队伍分散程度与地理位置分别控制；不是一次覆盖整个200 m地图 |
| 出生形态 | 环形对照、不规则队形、两簇分布 | 保留整体旋转和各车朝向随机化，独立记录地图、增强、出生与策略种子 |
| 出生合法性 | 有效地形支撑、车体足迹、初始间距 | 记录拒绝数与原因；共同终端可达性另外标注，不按在线策略能否成功筛选 |
| 最大车间距离 | 2.0 m | 新版停稳集合的待验证值；旧版1.25 m作为历史对照 |
| 离散度 | 0.75 m² | 到队伍质心的水平距离平方均值；旧值0.30 m² |
| 停车速度上限 | 0.05 m/s | 每辆车均需满足；旧值0.25 m/s |
| 驻留时间 | 连续5 s | 在0.2 s底层步长下为25步；中途失败清零；旧值8步/1.6 s |
| 停车角速度上限 | 0.1 rad/s | 新增每车检查，旧成功逻辑没有此门槛 |
| 终端地形 | 共同作业区、各车停车足迹、车间净空分别检查 | 接受分开检查的方向；物理尺寸与阈值仍需依据车辆及作业定义确定 |
| 平坦度分量 | 整体倾斜、去趋势粗糙度、局部台阶分别评估 | 不直接把旧0.18 m高差或0.25坡度解释为车辆安全规范 |
| 回合时限 | 96 s与180 s配对比较 | 20 s继续仅供接口诊断；主任务时限依据无学习闭环结果确定 |

以上数值是用户接受的实验起点，不代表最优参数或真实月球车安全验证。共同作业区的实际作业用途尚未定义；首次适配保留共同作业区语义。单独的“附近安全停车”版本需明确标注为不同任务。

## 通信实现要求

- 将完整消息范围、稀疏广播周期、稀疏消息最大范围、有效期分别配置；稀疏周期按固定物理距离或固定周期定义，解除与地图边界/对角线的绑定。
- 完整消息半径暂定24 m，完整消息原0.2 s刷新作为起点；稀疏更新的具体周期与最大距离尚未定值。保留消息年龄、载荷权限及过期后的保守处理，不通过延长有效期把旧消息冒充新状态。
- 当前NMPC接收消息有效期至多0.6 s，而远距离广播名义周期为1–4 s；适配时联合验证更新频率、有效期和过期状态下的执行行为。
- 更新配置加载器的12 m固定校验，核查消息缓存、观测、规划器及诊断输出。新方案不能只改一个YAML值后宣称24 m已生效。
- 24 m范围不保证所有出生样本完整互联：15–25 m半径的对向车辆可相距30–50 m，位置扰动也可能使8–12 m档部分车对超过24 m。记录完整消息图的初始连通性，并与稀疏消息可达性分开统计。

## 出生与终端实现要求

在地图有效支撑内选择地理中心，再生成队形；边界留量应覆盖出生半径、位置扰动、车体足迹和局部感知范围。自然采样与具有离线可达见证的样本分别报告，不能把无解或未知可行性场景静默删除。

逐车停车足迹与车间净空检查需要明确车体包络、朝向和定位/跟踪余量。旧中心距离0.42 m、碰撞距离0.28 m及接近惩罚距离0.72 m仅作历史参照，不因地图扩大而同比放大，也不作为新足迹检查已经完成的证据。

当前质心半径0.75 m圆盘只检查37个点，不能代替全部车体支撑检查。共同作业区尺寸不随2.0 m集合阈值自动确定；分开记录作业区、车辆足迹和路径安全。增大停车布局后同步检查奖励中的距离/离散度归一化、终端激活区与接近惩罚，避免新成功区域继续受到不必要的收缩驱动。

保持局部感知向前最远4 m和NMPC 3 s预测时域作为首轮对照。远距离闭环通过连续探查和局部规划验证，不因地图变大就扩大传感真值权限。地形阈值只在明确处理尺度和有效数据支撑的仿真地图上评估；0.1 m网格不增加源数据测量精度。

## 实施与验证顺序

1. 为新版任务建立独立配置与版本标识，保留exp167及NPB接口诊断以复现历史结果。
2. 完成通信参数解耦与24 m接入；验证边界内外消息、更新周期、过期处理及更换地图大小时通信条件不变。
3. 完成分层出生和合法性检查；记录地理位置覆盖、拒绝原因、初始通信图与共同终端可达性证据。
4. 完成逐车足迹检查与停稳判据，验证速度、角速度、保持中断及无效地形不会误报成功；记录尚未确定的车辆/作业假设。
5. 在真实底图、加坑、加坑石地图上配对运行无学习闭环，比较96/180 s，分别报告各出生档的成功、碰撞、超时、规划失败与终端判据失败原因。
6. 依据结果冻结任务、车辆、信息条件及预算。训练恢复仍需明确安排；本次接受方案不恢复训练、不续用旧pilot checkpoint、不恢复Active-DSTC。
