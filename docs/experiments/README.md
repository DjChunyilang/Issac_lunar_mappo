# 实验索引

除非实验文档另有说明，proxy strict gate 为：

```text
dmax_reduction_ratio <= 0.2
success_rate >= 0.9
collision_rate <= 0.02
timeout_rate == 0
```

PhysX / Jackal tracking 结果是 high-fidelity validation，不等于 Isaac Lab 物理训练结果。使用 checkpoint 前优先检查对应 run 的 `metrics/checkpoint_status.json`。
