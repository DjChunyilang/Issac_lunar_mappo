# exp074：可执行平整盆地搜索（BC reject）

## 目的

exp074 将“集合点足够平整”直接纳入最优搜索的可行性约束：候选中心以及半径 `0.10 m` 的 8 个等角实际质心偏移，都必须各自通过同一 `0.75 m`、37 点的平整度圆盘。这样搜索的是可执行的平整盆地，而非偶然合格的单点。为避免二次过度拉长行程，软平整度权重从 `1.50` 回调至 `0.25`；运行时真实质心 hard gate 完全不变。

## BC 快筛结果

128-update BC、seed `11023`、512 环境、320 步结果为：dmax ratio `0.2281`、success `0.6074`、collision `0`、timeout `0.3926`、最终实际质心平整率 `0.7891`。搜索可行率仍为 `1.0`，但平均初始 oracle 行程增至 `3.4974 m`，高于 exp073 的 `3.2422 m`；完整包络搜索的 BC 用时约 6 分钟，明显高于单中心搜索。

## 结论

该方法验证了硬约束包络能提升实际平整率，但路径代价使 dmax 显著失败，不能启动 4M。实现、配置解析和回归测试保留，作为后续在更高效局部 basin 表达或更强末段共同平移控制下的正确约束基础；当前训练主线仍采用 exp073 的单中心平整余量搜索。
