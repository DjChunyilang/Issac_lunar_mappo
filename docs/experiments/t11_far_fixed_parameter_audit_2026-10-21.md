## 6. 高层动作、持续决策与初始化

| 参数 | 值／行为 |
|---|---|
| 表达 | A1：Bernoulli HOLD 门控＋条件极坐标 MOVE |
| MOVE | `rho=2*(tanh(z_rho)+1)`，0–4 m；`beta=pi*tanh(z_beta)`，−π–π |
| 目标坐标 | 决策起点车身极坐标转换为固定 odometry 目标；续发时不随车重新平移 |
| 策略／GRU 周期 | 5 s；一次决策一次 GRU、一次 latent／log-prob 记录 |
| 重规划／控制安全检查 | 1 s／.2 s；局部到达、HOLD或安全制动不提前重采样 |
| 请求有效期／延迟 | 1／.5 s；激活边界向上取整为 3 个底层步＝.6 s |
| 终端信用屏蔽 | 真实终端持续≤3步，本次动作来不及生效：屏蔽 Actor 信用，仍保留 Critic 和向前信用 |
| 速度帽／末端航向 | A1 不学习它们；运动承诺和安全处理使用合法执行接口 |
| MOVE 均值初始 | rho≈2 m，beta≈0，近似车头前方；不是向心教师 |
| HOLD 初始 | bias=log(.35/.65)=−.6190392，加小输出权重，实际状态概率约 .35 |
| 连续噪声初始 | log_std=−.5+log(.25)=−1.8862944；latent std=.1516327 |
| 连续噪声范围 | log_std clamp[−5,1]；两维独立、全局可学习，不随状态变 |
| 输出头初始化 | 权重正交 gain=.01；MOVE bias=0；其余网络保持模块默认初始化 |
| 随机评估 | 真实门控与条件 MOVE 分布采样；日志记录原概率 |
| 均值评估 | logit>0 时 HOLD，否则 MOVE；MOVE 使用 latent mean |
| 概率与熵 | HOLD 原子＋条件 MOVE 密度；包含 tanh Jacobian 和物理尺度，MOVE 熵按 MOVE 概率加权 |
| 历史探索／辅助 | 停车 logit 偏置、方向辅助、离线预训练均关闭 |

5 s 决策不意味着一次 HOLD 必定完成 5 s 驻留：实际刹车／转向耗时后可能需要连续两次 HOLD。现有短训两次停到23/25步被下一MOVE打断的证据仍有效；这里保留原时间参数让正式实验观察其长期影响，不能把“取消课程”称作已修好持续性。

| 配置键 | 值 | 作用 |
|---|---:|---|
| `distance_progress` | 9.5 | 最大车距势差 |
| `dispersion_progress` | 6 | 离散度势差 |
| `distance_level`／`dispersion_level` | .13／.04 | 每步几何超限成本 |
| `flatness_progress`／`flatness_excess` | 2／.02 | 近集合区域平坦度势差／成本 |
| `hold_potential` | 12 | 实际驻留进度势差，不是选 HOLD 的固定奖励 |
| `energy_weight` | .003 | 能耗总权重 |
| `distance_cost`／`turn_cost` | .02／.007 | 平移／转动成本 |
| `terrain_weight` | .1 | 地形总权重 |
| `roughness_cost`／`traversability_cost` | .15／.15 | 粗糙度／通行度 |
| `speed_loss_cost`／`height_change_cost` | .14／.09 | 地形减速／高度变化 |
| `collision_cost`／`clearance_cost` | 100／2.4 | 碰撞事件／有效圆净空超限 |
| `success_bonus` | 130 | 真实完整任务成功 |
| `failure_penalty` | 55 | 碰撞／越界终端 |
| `timeout_penalty` | 80 | 当前候选3600 s截止终端 |
| `gather_scaling` | log1p | 几何超限尺度压缩 |

核心公式（g 是底层折扣，D 是实际区间底层步数）：

```text
ed = log1p(max(dmax−12,0)/12)
es = log1p(max(S−30,0)/30)
Phi_gather = −9.5*ed − 6*es
r_gather = g*Phi_gather(next) − Phi_gather(start) − .13*ed_next − .04*es_next

near = clip((24−dmax)/12,0,1)
flat_excess = max(flatness_cost−1,0)
Phi_flat = −2*near*flat_excess
r_flat = g*Phi_flat(next) − Phi_flat(start) − .02*near_next*flat_excess_next

Phi_hold = −12*(1−clip(hold_count/25,0,1))
r_hold = g*Phi_hold(next) − Phi_hold(start)
r_energy = −.003*(.02*mean(abs(v))*.2 + .007*mean(abs(omega)))
r_terrain = −.1*mean(.15*roughness + .15*(1−traversability)
                     + .14*(1−terrain_gain) + .09*abs(height_change))
r_clearance = −2.4*max(2*effective_radius−minimum_center_distance,0)
```

真实终端所有后继势清零；碰撞可同时承担 −100 与 −55。势差、区间累加、GAE统一使用g；分段区间按已推进步数加权。平移能耗含dt，转动和地形项按当前离散定义不另乘dt，本轮不改dt。

本次仅做远距代数检查：对称队形在一底层步内径向内移 .1 m／保持／外移 .1 m，忽略相同执行成本，三项势差加几何成本如下。

| 基础 R | 内移 | 保持 | 外移 |
|---:|---:|---:|---:|
| 200 m | −.679664 | −.690515 | −.701361 |
| 250 m | −.725813 | −.734493 | −.743170 |
| 300 m | −.763193 | −.770426 | −.777657 |

排序正确，但**有效进步仍可对应负的即时奖励**，改善体现在相对回报。R=250 m 时 .1 m 内移仅比保持多约 .00868；远距每步绝对成本远大于微小进步差，需结合 Critic、优势及完整回合比较，不能仅看 reward 曲线上升与否。该检查不是实际可执行轨迹、HOLD反事实优势或收敛验证。

## 12. 审计结果和启动边界

原审计通过19层配置、profile、全部奖励／PPO／MPPI有效值及派生时间、4096个静态几何样本和远距奖励代数排序。当前修订另核对月面三份源数据SHA、四个不重叠1km窗口、3600s配置解析、864,000步评估预算及历史实际速度；未变设置继续复用原证据。**两次环境推进与优化更新均0，没有运行训练或学习探针。** 月面场景包、真实足迹出生、固定入口和有界缓存尚未接通，不能写成生产闭环通过。

审计时最值得重点看的是：

1. **任务覆盖**：仅远距及月面已确定；具体NPB窗口、坑石参数、R200–300 m加逐车.9–1、3600s候选及近似四象限出生边界待审。
