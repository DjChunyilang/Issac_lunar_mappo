# 真实地形、统计校准合成地形与增强假设的比较协议

更新：2026-09-25。地图主线已确定为[真实DEM与NASA模型增强](../architecture/lunar_map_mainline.md)。
基础与增强地图、GPU短程接口检查已经完成，见[NASA SFD验收](nasa_sfd_v2_2026-09-24.md)。
本协议用于后续数据集与学习比较，**尚未启动训练、尚未执行区域统计拟合**。
物理真实性待验证项应如实报告，不作为继续生成仿真地图的绝对前置条件。

## 先决条件与冻结顺序

1. 先完成真实数据派生训练地图及环境接入，验证几何尺度、缺测处理和运动/观测查询一致性。记录所用仿真任务与车辆假设；尚缺的真实接触安全证据作为解释边界，不阻塞这一链路。
2. 扩展真实区域并锁定原始产品、源关系与划分清单hash。NPB当前样例已用于开发，三个增强种子不构成独立区域。LUPEX原六区四组（CR1、GR1+GR2、LP1、MP1+MP2）及跨源分组记录保留为补充评估候选；正式训练集应按实际覆盖与来源关系另行冻结，不能直接把已有审计划分宣称为已完成训练评估。
3. 独立样本单位是地理/来源组。采用留组评估时，开发仅在非测试组进行；同地点裁剪、重采样、增强及重复产品继承同组。旧LUPEX嵌套12组合不是12个独立测试样本；同一外层测试组只汇总一次。单NPB内的空间留出不宣称跨区域泛化。
4. 冻结任务、车辆、信息条件、控制执行链、指标、失败分类和预算核算方式，再开始方法比较。通过这些门槛后另提训练预算，本轮没有预设90万次交互。

全体区域的此次质量审计用于披露数据能力，不作为测试地形上的策略调优。当前区域级相关尺度在至少一个方向存在删失，没有建立可证明独立的裁剪间距，因此主基准使用完整区域引用。后续窗口仅为同一组内的相关视图；任何裁剪、重采样、增强和同地重复产品继承原组，不能随机打散。

## 合成统计校准协议

**拟合输入**：每折仅使用`train`区域；禁止用`validation/test`的坡度分位数、敏感性尾部、失败场景或外层结果重设生成参数。处理尺度与掩码规则必须一致。

可校准量为可解析尺度上的双方向坡度—基线曲线、去趋势RMS分布、相关/半方差曲线、完整支持覆盖及宏观起伏。各区域先单独统计再按区域等权汇总，不能让一个大区域或大量相邻裁剪主导拟合。16/32米只是本轮可继续调查的描述尺度，需报告缺测导致的条件分布偏差；不把这一分布当成完整真实表面的无偏统计。

校准过程记录：输入区域及校验和、基线、有效样本掩码、生成器版本、随机种子、目标统计、损失权重、参数搜索域与停止规则。参数范围要来自开发区可解析统计或具体外部证据，不能沿用固定幅度倍数。用内层验证组检查描述量与下游行为，不据外层测试组反复拟合。

**未解析细节**：当前轨道产品不能充分识别车辆接触尺度的石块、微坑与摩擦。已实现的NASA坑石模型和未来补充细节均作为独立假设增强层，记录依据/无依据部分、幅度频谱、空间相关性、种子和底图hash。LUPEX敏感性图与LOLA总高程RMS含义不同，均不能直接当作独立像元高斯sigma。任何误差扰动都需要说明结构、相关尺度和遗漏误差，不默认生成。

## 公平比较矩阵

| 数据条件 | 当前状态 | 后续比较要求 |
| --- | --- | --- |
| 真实数据裁剪与插值/重采样的基础图 | 已生成并接入无学习环境检查 | 主线的基础对照，保留来源、支持掩码与地理隔离 |
| 同底图＋NASA模型坑 | 已生成三个种子，坑形保留旧实现 | 与基础图配对，固定其他条件，分析坑层的影响 |
| 同底图＋NASA模型坑石 | 已生成三个种子，通过GPU短程检查 | 主线增强条件，与加坑版本共享坑目录；记录模型尚未区域标定 |
| 开发区统计校准的合成地形 | 仅协议，尚未拟合 | 后续对照，使用相同任务、车辆、信息、算法和预算核算 |
| 原有纯随机地图任务 | 历史/机制对照 | 任务定义不同时成功率不得直接排名 |


“仅局部信息”与“显式轨道先验”分成两个信息条件，不能在某一种地形训练时额外开放全图。机器人局部信息不能直接等同于高精度真值。算法比较晚于地形数据比较；先固定一个可运行的执行链，不同时换算法和训练地图后把收益归因于真实地形。

## 报告与停止规则

- 各外层区域组分别报告结果，同时给出按区域等权的汇总；少量组只支持受限描述，不宣称月球总体或跨仪器泛化。
- 分开报告任务结果、数据支持不足、规划失败、控制失败、通信问题与假设不满足；低可信/陡峭/缺少平地/算法失败场景不能因结果差而删除。
- 敏感性分层采用开发阶段预定义规则；本轮按产品计算的p95诊断标记不是未来通用安全阈值。缺测与重建疑似伪影独立列示。
- 记录训练交互、有效样本、墙钟时间、执行吞吐量和计算硬件。公平条件与停止规则事前冻结，不因测试失败追加到满意为止。
- 报告仿真表面及车辆模型的假设，不将仿真成功解释为真实车辆安全认证。训练启动沿用当前明确暂停的安排，在地图与环境接入验证后单独提出；不以缺少真实车辆安全证据本身阻止仿真训练。

最终比较包需要配置快照、产品/划分hash、特征版本、方法实现hash、学习与评估日志、区域级指标、失败清单、增强假设登记表。点运动smoke或图像观感均不能替代车辆可达、安全或任务成功证据。
