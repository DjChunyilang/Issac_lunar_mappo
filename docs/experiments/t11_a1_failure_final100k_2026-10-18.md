# A1完成100k后的集合失败诊断

结论：A1在队形尚远未达标时形成了广泛的HOLD偏置，末期约95%的动作停车，偶尔MOVE也很快被下一次HOLD打断。MOVE仅有微弱向心偏置，晚期PPO局部梯度仍推动HOLD概率上升。因此车辆未持续缩小队形，就逐渐停在原处附近。执行、目标坐标或最终停车地形没有构成本窗口的主要阻断。

## 范围与结束条件

2026-10-18检查`oom_fix_owner16_20261017_01_a1`。`metrics/session_summary_000061.json`确认100,000有效团队转移全部完成，最终checkpoint为`checkpoints/update_000061.pt`及配套owner分片；这是signal学习结果，未通过集合验收。

具体问题是“为什么未集合就停车”：最小验收为最终任务判据、HOLD/MOVE真实执行、更新前HOLD概率和实际优势梯度。限定14个增量批次、三个执行代表批次及四个学习代表批次；证据足以决定下一步后结束。本轮只读已保存产物，无新仿真、策略更新或队列变更。

## 已确认的失败机制

### 队形尚很分散就选择停车

按实际采样姿态检查第16、47、60批：

| 指标 | 第16批 | 第47批 | 第60批 |
| --- | ---: | ---: | ---: |
| HOLD比例 | 50.81% | 87.93% | 95.19% |
| 选择HOLD时平均最大车距（m） | 27.87 | 28.98 | 28.40 |
| 选择HOLD时平均离散度（m²） | 134.35 | 142.46 | 137.25 |
| MOVE后下一秒转HOLD | 50.03% | 88.85% | 94.15% |
| MOVE目标指向当前质心的比例 | 55.19% | 54.30% | 53.05% |

这些代表批次的全部HOLD选择都发生在最大车距和离散度同时超标时。第60批81.28%的HOLD发生在最大车距>24 m时，90.29%发生在离散度>90 m²时，不能解释成接近成功后的正常停车。

末期MOVE虽仍有2–3 m局部目标，却大多只持续一个高层周期。连续MOVE方向变化>90°在第16批占45.30%；第60批只剩23对连续MOVE，不用这23对作稳定方向频率判断。更充分的证据是94.15%的MOVE下一秒即切回HOLD。

### 规划和执行按请求正常工作

第47、60批HOLD和MOVE规划有效率均为100%。按真正已激活意图分组，两批共6,879个MOVE车步全部`verified/unchanged`，记录的安全纠正为0；平均实际线速分别0.0896、0.0868 m/s。HOLD正常制动，平均速度降至0.00235、0.000876 m/s。

第16批MOVE拒绝28/4,030，原因均为`neighbor_swept_clearance`；另有HOLD停车规划未验证37/4,162，单列而不混算为MOVE拒绝。第48–61批全部执行复核通过率99.9425%。这些结果不支持“末期主要被安全层拦停”。

请求均按0.6 s激活延迟、激活后1 s有效期接收。目标桥接最大误差3.78e−15 m，原请求到激活请求目标无改写。执行统计使用真正激活的意图，排除了新HOLD采样后等待期间旧MOVE仍在运行的混淆。

### 学习已形成HOLD偏置，晚期局部梯度继续强化它

使用采样批次`t`的原`samples.hidden`及更新前`t-1`学习器checkpoint重建概率；原log-prob最大误差低于1e−6。用保存的奖励、value、next_value、duration和终止掩码重算GAE，其均值/标准差与原日志吻合。

| 采样批次 | 重建平均HOLD概率 | 增加共享HOLD logit的actor局部梯度分数 |
| --- | ---: | ---: |
| 16 | 51.10% | −0.01186 |
| 35 | 66.04% | −0.00259 |
| 47 | 87.60% | +0.01756 |
| 61 | 94.85% | +0.01130 |

分数为`mean(A_normalized * (hold - p_hold))`，对应首轮ratio=1时的actor目标对统一HOLD logit偏移的方向；正值鼓励HOLD增加。它不包含熵项、后续clipping及Adam状态，不能等同于完整多轮更新的因果分解。第47批四车分数均为正；第61批仍为正。早期两个抽查批次为负，因此不声称每批都奖励HOLD。

第61批HOLD概率中位数95.24%，四车均值接近，全部采样状态下概率均大于0.5，说明这是广泛的停车偏好。第47、61批更新后的HOLD头，在同一保存hidden上又分别将平均HOLD概率提高0.793、0.268个百分点；这里只隔离头参数效应，不把旧hidden套新头称为完整新策略前向。

PPO将相同团队优势用于四辆车。按HOLD/MOVE分组的优势均值会混入状态与其他车动作，不能直接当作逐车因果收益。本轮能确认“实际梯度正在继续强化停车”，尚未用同状态干预证明是奖励权重、Critic误差或探索哪一项单独导致了该偏好。

## 对学习原因的判断

最符合现有证据的机制是：MOVE尚未形成可靠、连续的向心行为，A1逐渐转向少动；HOLD减少了运动机会，末期MOVE样本更少且常被迅速打断，局部更新又在加强HOLD。这个退化过程比“地形太难”“安全层拒绝”“优化器没更新”更能解释实际轨迹。

物理时间上的信用传播较短，是下一轮需检验的解释：gamma=0.99、lambda=0.95用于0.2 s底层步，回报折扣半衰13.79 s、GAE trace半衰2.26 s；360 s末超时罚从起点折扣后约−1.12e−6。Critic仍可通过bootstrap传播价值，不能仅据半衰期认定唯一根因。

`success_hold`每步+0.12来自负势能的折扣差分，且不依赖采样动作是否HOLD。真实驻留一直为0；宏步折扣、GAE时长及终止势能归零接线一致，完整折扣势能只剩初态常数。因此没有发现“停车被误发成功奖励”的代码错误。

[A0同期诊断](t11_a0_failure_update35_2026-10-18.md)去掉HOLD后仍缺少向心方向且整体发散，说明仅取消HOLD不足以解决MOVE学习。两者只作行为机制参照，不以不同训练预算和迁移历史作正式性能排名。
