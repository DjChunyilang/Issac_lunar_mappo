2026-10-19。用户要求先深度研究、再判断下一步。本记录覆盖此前“直接转向方向引导”的建议；[三组比较](t11_decision_credit_results_2026-10-19.md)的数值与筛选失败事实保留，算法归因与下一步排序以本记录为准。

当前最有根据的下一步是：**先做冻结批次的价值学习与实际策略更新诊断，再用分离门控／方向噪声的同状态对照判断行为来源。暂不直接实施方向辅助、改动作表达、加MOVE奖金或续训。**原因是已有数据同时暴露了价值基线未校准、梯度裁剪与Adam动量耦合、初始化先验与确定性阈值混杂、停车状态没有训练覆盖；这些竞争解释尚未被排除。

## 1. C的8.39米改善尚不能算作学会方向

旧远距离owner 0快照中，16辆车有14辆的正前方已经落在真实团队中心的向心半平面。C最终均值策略首步条件MOVE距离仅1.9978–2.0002 m，方向为车头相对−0.058°至+0.822°，接近初始化的`rho=2 m, beta=0`。场景生成本身对部分初始朝向有朝目标槽位的偏置，见`upstream_s05_cases.py:80`。

确定性分支按`hold_logits > 0`选择HOLD（`actions.py:145`）。C最终远距均值概率范围0.49772–0.49925，使64个动作全部MOVE；初始化则64个全部HOLD。网络分布只需小幅跨过0.5，执行行为即可翻转。这强烈削弱“时间折扣已经教会向心”的解释，但还不能断言8.39 m全部由初始化先验产生。缺少的直接对照是**初始化条件均值＋强制MOVE**。

固定评估种子下，C最终与初始化远距随机策略的64个HOLD/MOVE序列逐项相同，近距也相同，均35/64 HOLD。首步目标最大变化仅远距0.0322 m、近距0.0150 m。连续latent标准差从`[0.606531, 0.606531]`变为`[0.607256, 0.606186]`，没有明显收窄。经`beta=π tanh(z)`映射，方向latent的一标准差对应约±97.46°；这不是物理角度的标准差，但显示请求分布很宽。向心半平面比例也只测方向内积为正，不保证足够径向推进或能在5秒内完成转向。

因此“均值能走、随机不靠拢”至少有三种竞争解释：先验被门控释放、方向／分支噪声破坏执行、学习更新不足。初始动作分布对PPO学习可能有很大影响，原始大规模研究也明确观察到这一点，但其MuJoCo参数不能直接照搬到本项目。[Andrychowicz等，2021](https://arxiv.org/abs/2006.05990)

## 2. 近距离4/4变0/4，不等于遗忘了学会的停车技能

按每条执行记录的`active_envs`掩码扫描三组全部20批：

| 训练覆盖 | A | B | C |
| --- | ---: | ---: | ---: |
| 实际环境步 | 200,000 | 200,000 | 200,000 |
| 完整包含条件`contained`为真 | 0 | 0 | 0 |
| 即时成功条件为真 | 0 | 0 | 0 |
| 驻留计数大于0 | 0 | 0 | 0 |
| 最小最大车距（m） | 16.2917 | 14.9992 | 13.2823 |

任务要求最大车距≤12 m，60万步没有任何一步达到这个条件，更没有成功驻留的学习样本。环境reset回到各自固定初态（`upstream_environment.py:418`）。初始化近距均值策略已经4/4成功，来自全HOLD先验，不能称为训练学得的停车能力。

近距四例将同一方阵与所有车头共同旋转；在平地和车体坐标观察下接近等价。它们能检查旋转一致性，不能当成四种独立停车几何。C的近距失败仍是实测，但优先解释应包含**训练支持范围缺失与门控整体移动**，不能直接认定网络分不清远近或发生灾难性遗忘。

单种子与四个固定初态足以发现上述机制线索，不足以排除整个持续决策／时间折扣方向。先做同状态机制对照比立刻增加全程训练种子更有定位作用；后续方法比较再补不确定性和独立初态。[Agarwal等，2021](https://arxiv.org/abs/2108.13264)

## 3. C的价值基线与实际更新幅度是优先排查对象

末批更新前及最后一轮记录：

| 指标 | A | B | C |
| --- | ---: | ---: | ---: |
| 价值目标均值 | 5.559 | 6.834 | −30.130 |
| 当前V均值 | 3.731 | 3.821 | −4.445 |
| Critic解释方差 | 0.605 | 0.208 | 0.077 |
| 原始Critic MSE | 3.550 | 11.058 | 898.280 |
| MSE／目标方差 | 6.745 | 4.414 | 3.476 |
| 全局裁剪前梯度范数 | 15.482 | 26.423 | 290.771 |
| 最后一轮更新前approximate KL | 1.69e−4 | 7.87e−4 | 4.12e−7 |
| 初始化至最终actor参数变化L2 | 1.395 | 1.453 | 0.450 |

原始MSE的跨组差异不能直接排名；除以目标方差后排序就不同，且EV不包含均值偏差。需要联合看校准偏差、EV和参数／策略变化。C末批没有终端，巨大偏差并非只来自该批末尾的超时惩罚。

Actor与Critic网络彼此独立，却在`upstream_training.py:168–173`合并loss后，对全部参数作一次全局裁剪，再由同一个Adam更新。C全局范数从首批53.585升至末批290.771，公共梯度缩放从0.01866降至0.003439。全局裁剪本身属于常见PPO实现选择，并非见到它就能判bug。[PPO实现细节](https://iclr-blog-track.github.io/2022/03/25/ppo-implementation-details/)

Adam会适应梯度尺度，所以不能声称actor参数更新被直接缩小291倍。使用update19的同一Adam槽、末批原latent与sampled hidden，离线改变**当前这一步**头部梯度缩放，得到C预期参数增量比：`mean.weight`6.45倍、`mean.bias`5.53倍、`hold_logit.weight`4.17倍、`log_std`16.20倍。这支持公共裁剪与已有动量确实影响有效步长。它只固定hidden做头部代数反事实；熵使用新固定随机数，不是全网络精确重放，也不能证明长期分开裁剪必定更好。[Adam](https://arxiv.org/abs/1412.6980)

C末批头部PG原始范数0.08636，带权熵梯度0.000893，整体不是熵梯度压倒PG；但HOLD bias上的熵梯度约为PG的13.1%。没有证据支持先盲减熵系数。

C优势总方差的81.08%来自各环境时间均值之间的差异，A/B分别32.83%／12.18%。这提示未校准的状态基线可能占据大量信号；不能把它当作动作信用错误的证明，也不能未经验证改为逐环境优势标准化。MAPPO原论文将价值尺度、Critic输入、数据使用、裁剪和batch大小列为重要因素；价值归一化可列为候选，但必须在GAE中还原价值单位，且不是本项目已验证的修复。[Yu等，2022](https://arxiv.org/abs/2103.01955)

## 4. 时间折扣改变了多个学习条件

| 量 | A/B | C |
| --- | ---: | ---: |
| 回报折扣半衰时间 | 13.79 s | 68.97 s |
| GAE trace半衰时间 | 2.26 s | 11.30 s |
| 跨5 s动作的GAE递推系数 | 0.216 | 0.736 |
| 360 s后的回报权重 | 1.39e−8 | 0.02683 |

B/C首批sampled hidden和全部动作逐值相同，是天然同轨迹对照；两组区间奖励相关系数0.536、GAE优势相关系数仅0.222。C同时改变势差、区间回报、bootstrap权重、GAE跨度和价值目标尺度，不能简单解释为只修复了一个“时间单位”。GAE本来就在价值基线偏差与方差之间取舍。[Schulman等，2016](https://arxiv.org/abs/1506.02438)

同样，B/C只有8,000团队决策样本，A有40,000，三组都是100次Adam更新。相同物理预算控制了环境交互成本，却没有控制独立动作样本数、GRU推进次数或有效梯度信噪比。预算不足仍是竞争解释，但当前不能用继续堆训练来替代定位。

## 5. 势差奖励与单次动作信用必须分开

保持最优策略的势差形式是`F=gΦ(next)−Φ(start)`。有限非终端窗口满足：

```text
Σ g^k F_k = −Φ(s0) + g^T Φ(sT)
```

因此20秒奖励中包含末态势边界；加上尚不准确的Critic尾值，并不构成一份独立的奖励正确性证据。`success_hold`在驻留计数为0时势为−12，旧折扣下不移动也产生每步+0.12的势差，这是常量势的折扣效果，不是“提前HOLD真的获得了成功奖励”。真实终端势归零、折扣一致时，整回合势差贡献由初态决定。[Ng等，1999](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf)

本轮还用已记录几何剥离20秒首尾势项（这些分支flatness势为0、驻留计数为0、100步内非终端）：

| 口径 | HOLD | 持续向心 | 向外 |
| --- | ---: | ---: | ---: |
| A/B：剥离势差后的奖励 | −19.430 | −12.105 | −28.878 |
| C：剥离势差后的奖励 | −27.793 | −15.591 | −44.034 |

排序仍然是向心最好，所以“只是末态势制造了假改善”也不足以解释全部结果。但这只证明20秒联合动作序列更好；PPO需要的是当前状态做**一次动作后再跟随当前策略**的优势。四辆车全程向心的回报不能回答单车、单决策的信用问题；跨状态比较`E[A|HOLD]`与`E[A|MOVE]`也有状态分布混杂。COMA论文的反事实思想可用于设计检查，并不意味着立即换算法。[Foerster等，2018](https://arxiv.org/abs/1705.08926)

## 7. 下一步的具体顺序与停止条件

采用能把原因分开的最小探针，而不是同时修改奖励、表达、优化器与训练初态。调试资料强调隔离价值、策略和环境，并检查实际参数变化；本项目已有工程契约检查，下一步应补的是**学习信号与更新效应**。[Andy Jones：RL调试经验](https://andyljones.com/posts/rl-debugging.html)

**第一优先：冻结批次的全网络更新与Critic拟合诊断。**

保留B作为旧折扣控制，C为主要对象。补齐同一小批真实on-policy数据的`obs/state/initial hidden/latent/log_prob/reward/next_value/duration/RNG`，在独立内存副本上比较原公共裁剪与Actor/Critic分开裁剪。分别记录原始梯度、实际Adam增量、各头KL、PG目标变化和留出状态动作敏感性；不以“KL越大越好”作为验收。同时固定价值目标，仅训练诊断副本的Critic，检查误差能否下降、是否只是学了常数偏移、留出误差是否同步改善。

当前归档只保存`sampled hidden`与标量学习项，没有保存完整`obs/state`，所以本轮头部反事实不能冒充完整更新重放（`upstream_decision_experiment.py:183`）。下一次可只重建C/B首批的一个owner、25次决策，物理轨迹相同处复用；约2,500底层步即可得到4环境×125 s的完整输入。它是独立诊断预算建议，**本次没有执行**，不从已结束三组追加扣费，也不写回训练状态。

停止／分流：若实际更新方向或概率重放出错，先修实现；若Critic固定目标都拟合不好，先定位尺度、输入或优化；若公共裁剪显著削弱有效PG改进，而分开裁剪改善并且未产生过大策略漂移，才将价值／优化修复列为下一实现候选。若只放大更新却没有改善动作价值排序，继续第二项，不宣称找到根因。

**第二优先：用最少执行对照分离先验、随机性与单次信用。**

先补“初始化条件均值＋强制MOVE”，与已有C均值轨迹比较，再选择必要的门控确定／方向随机、门控随机／方向确定分支。若初始化也能近似复现8.39 m，则撤销方向已学会的解释；若只去除方向噪声就恢复推进，则优先研究探索尺度而不是扩大动作表达。

随后在同一合法状态，固定其余车及后续策略，只替换一辆车一个决策为HOLD／向心／向外，用共同随机数比较实际增益与对应TD／GAE排序。这些干预不进入PPO。若实际增益与优势相反，修价值／信用；若排序正确且更新有效、随机执行仍无向心趋势，方向引导才有更充分依据。每个诊断先设小预算，已有结果足以分流即停止，不把所有分支一次跑完。

**停车问题单独按覆盖缺失处理。**在确认更新链路能学习状态依赖动作后，设计少量近集合、不同相对车头与非正方形初态的HOLD／MOVE可学习性探针。若局部停车能学、原训练始终到不了这些状态，后续才优先采用近远混合初态／课程；若信息存在却局部探针都学不会，继续定位学习链路。不能把未经训练的近距失败直接作为添加方向监督的理由。

本轮研究已足够决定**先诊断价值与更新链路**，尚不足以决定直接更换奖励权重、方向表达或算法。方向辅助、探索尺度、价值归一化、独立裁剪、初态课程均保留为有条件的候选，不同时实施。
