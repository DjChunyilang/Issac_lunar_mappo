# exp129：冻结状态配对动作干预诊断

## 目的

exp128 表明集合进度可由联合动作解释，但现有安全与地形奖励不可辨识。exp129 不再拟合价值模型，而是在完全相同的车辆状态和地形上，只扰动一辆车的动作，并重新计算局部 quintic 轨迹风险与轨迹安全裕量，以测量直接局部响应。

该诊断不推进干预分支的环境状态，不修改 Actor、通信缓存、奖励或控制器。

## 方法

对冻结策略均值动作中车辆 (i) 的两个动作维度分别施加 ​\(\pm\delta\)，其中 ​\(\delta=0.15\)。利用实际裁剪后的动作间隔计算中心差分：

\[
\frac{\partial y_i}{\partial a_{i,k}}
\approx
\frac{y_i(a_{i,k}^{+})-y_i(a_{i,k}^{-})}
{a_{i,k}^{+}-a_{i,k}^{-}}.
\]

定义相对路径风险梯度 ​\(\nabla_a R_i\) 和同时间戳轨迹最近邻距离梯度 ​\(\nabla_a M_i\)。降低风险的方向为 ​\(-\nabla_aR_i\)，提高安全裕量的方向为 ​\(\nabla_aM_i\)。二者的一致性为：

\[
\cos\theta_i=
\frac{(-\nabla_aR_i)^\mathsf T\nabla_aM_i}
{\lVert\nabla_aR_i\rVert_2\lVert\nabla_aM_i\rVert_2}.
\]

正式诊断使用 seed17023、64 个环境、完整 480 步，每 8 步采样一次，共 15,360 个车辆—状态样本。所有执行期过滤器和安全投影保持关闭。

## 结果

| 指标 | 结果 |
| --- | ---: |
| 相对风险梯度范数中位数 | 0.0665 |
| 安全裕量梯度范数中位数 | 0.6713 |
| 归一化相对风险响应中位数 | 0.5226 |
| 归一化安全裕量响应中位数 | 0.1786 |
| 目标方向余弦均值 | 0.0076 |
| 目标方向余弦中位数 | 0.0202 |
| ​\(\cos\theta>0\) 比例 | 50.93% |
| ​\(\cos\theta>0.5\) 比例 | 27.64% |
| ​\(\cos\theta<-0.5\) 比例 | 26.94% |
| 有效中心差分比例 | 100% |

Actor 参数哈希与探针动作前后完全相同。

## 结论

动作对地形风险和车辆安全均有明确局部影响，因此问题不是动作空间或 quintic 链路失效。但两项目标的局部最优方向整体近似正交，强一致与强冲突状态比例接近对称。exp126 只强化地形信用时，约四分之一状态会沿显著损害安全裕量的方向更新，这与其 collision 和重复冲突激增一致。

因此：

- 不继续增加固定地形信用系数；
- 不扫描地形—安全静态权重；
- 不因存在局部冲突而恢复方向性安全投影；
- 不启动新的 4M 训练。

若后续修改训练目标，必须先提出单一、状态相关且仍满足严格去中心化执行边界的多目标信用定义，并重新制定门限；不能把 exp129 直接当作训练教师或在线方向 mask。
