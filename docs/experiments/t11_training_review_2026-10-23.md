## 3. 回报为何不能单独当作进展

两轮全部已结束回合中，原始回报与寿命的 Pearson 相关分别为 **−0.9973、−0.9946**：在当前失败样本里，越快结束的回合往往得到越高的原始回报。

奖励实现提供了相应解释：距离／离散度、地形和障碍负项随执行步累积；gather 与 success_hold 又包含势函数差，所有真正终端（包括地形失败）的后继势均归零。因此失败结束时也会出现正的势差结算。即使驻留计数始终为零，原始 `success_hold` 也约为 +12；新 run 的回合均值 +12.53 并不表示停车取得进展。两 run 已结束回合的最终驻留计数均为零。

这支持“回报略升可能主要反映少承受几步惩罚”的判断，但不能单凭相关性断言策略在主动寻求失败。这里不据此改动奖励。源码依据为 `upstream_reward.py` 的 `potentials()` 与 `advance()`；成功仍由真实任务判据单独判断。
