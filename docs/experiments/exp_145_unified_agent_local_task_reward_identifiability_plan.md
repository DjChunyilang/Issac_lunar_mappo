# exp145：统一逐车局部任务回报动作辨识审计计划

## 目的

exp144表明继续训练会增强terrain输入对动作的影响，却不会降低实际quintic路径风险。exp128–exp140又分别说明：集合进度具有动作辨识度，逐车地形与安全结果存在局部响应，但把某一个单项信用附加到共享团队advantage会破坏其他目标。

exp145不再追加“地形信用”或“安全信用”。它只离线审计一个统一的逐车任务语义，判断同一辆车的观测与动作能否同时解释其集合、地形和安全结果。审计失败则不实现新的训练算法；通过也只允许形成训练计划。

## 逐车目标定义

### 局部集合进度

令其余车辆质心为：

\[
\bar{\mathbf p}_{-i,t}
=
\frac{1}{N-1}\sum_{j\ne i}\mathbf p_{j,t}.
\]

逐车集合势函数和一步进度定义为：

\[
\Phi_{i,t}^{g}
=
-\left\|
\mathbf p_{i,t}-\bar{\mathbf p}_{-i,t}
\right\|_2,
\]

\[
g_{i,t}=\Phi_{i,t+1}^{g}-\Phi_{i,t}^{g}.
\]

该量仅用于训练诊断，不进入Actor观测；它不包含Oracle集合点或全局槽位。

### 局部地形结果

使用现有同距离、零转向参考轨迹：

\[
t_{i,t}
=
-\left[
R\!\left(\tau_{i,t}(\rho,\beta)\right)
-R\!\left(\tau_{i,t}(\rho,0)\right)
\right].
\]

正值表示当前动作生成的quintic轨迹比同距离直行参考风险更低。

### 局部安全进度

令 \(d_{i,t}^{\mathrm{near}}\) 为车辆 \(i\) 到最近邻的距离，沿用环境已有的 `safety.near_distance=0.72 m`：

\[
\Phi_{i,t}^{s}
=
-\max\left(0,0.72-d_{i,t}^{\mathrm{near}}\right),
\]

\[
s_{i,t}=\Phi_{i,t+1}^{s}-\Phi_{i,t}^{s}.
\]

exp145只审计该连续安全结果；真实collision终止单独统计覆盖率，不混入即时回归目标。

### 统一目标

在训练数据上分别对三项进行零均值、单位标准差归一化：

\[
u_{i,t}
=
z(g_{i,t})+z(t_{i,t})+z(s_{i,t}).
\]

该等权和只用于判断统一语义是否可辨识，不是已批准的环境奖励系数。

## 诊断方法

冻结exp125 `relative_quintic` 的t2048 checkpoint。使用101维本车Actor观测，比较结构与容量完全相同的两个回归器：

- `local_obs`：只输入本车101维观测；
- `local_obs_action`：输入本车101维观测和本车2维动作。

二者同时预测 \([g_{i,t},t_{i,t},s_{i,t},u_{i,t}]\)。动作增益定义为：

\[
I_y
=
\frac{operatorname{MSE}_{o,y}-operatorname{MSE}_{o,a,y}}
{\operatorname{MSE}_{o,y}}.
\]

固定数据规模：

- 训练seed `39023`：128环境、480步；
- 验证seed `40023, 41023`：每种子64环境、480步；
- 三个模型初始化seed：`7, 17, 29`；
- 两层128单元ELU回归器；
- Actor与checkpoint全程冻结。

## 启用门限

只有以下条件全部满足，才允许形成逐车local-advantage训练计划：

- \(g\)、\(t\)、\(s\) 在两个验证种子上的平均动作增益均不低于15%；
- 三个分量各自的最差验证种子动作增益均不低于15%；
- 统一目标 \(u\) 的平均及最差种子动作增益均不低于20%；
- 三个原始分量在每个验证种子上的标准差均大于 \(10^{-4}\)；
- 安全分量在每个验证种子上的非零比例不低于8%；
- 地形分量正、负样本比例在每个验证种子上均不低于10%；
- Actor参数摘要与固定探针动作变化均为0；
- 数据收集仍使用101维严格去中心化观测，目标计算不得反向进入Actor输入。

失败后停止逐车回报方向，不调整等权归一化系数、不删除失败分量、不直接训练。通过也只允许制定共享Actor配合逐车advantage的实现计划，不能直接启动4M。

## 明确不做

- 不把Oracle、集合槽位或全局质心加入Actor；
- 不增加GNN、GRU、注意力或消息编码器；
- 不恢复安全投影和方向mask；
- 不使用BC、CBS路径或预测冲突作为教师；
- 不同时更改Actor结构、通信、课程或执行链路。
