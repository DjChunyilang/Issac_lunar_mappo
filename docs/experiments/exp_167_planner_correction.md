# exp167：规划层可行前缀与停车语义修正

## 目的

2026-09-18，根据用户“实施修正”的要求处理[固定目标诊断](exp_167_fixed_goal_diagnosis.md)发现的问题。只修改规划—执行链及其遥测、测试和配置版本；不恢复网络训练，不修改真实任务安全距离、成功条件、传感范围、奖励或通信分级规则。

## 配置与实现

配置增加 `local_goal.planner_revision: prefix_consistency_v2`。训练入口检查此字段，同时保留 checkpoint 的实现 hash 检查，避免把旧 pilot checkpoint 无提示地混入新算法。Actor 请求仍为原始四维动作，不以执行前缀替换 PPO 动作。

### 地形参数与输出轨迹

每次优化后按当前本地缓存重算控制轨迹，记录它与求解器内部 shooting 节点的最大位置差。差异超过 0.01 米且尚有一半时限时，沿新控制轨迹刷新地形参数，再进行一次有限求解；每次最多 6 次 SQP，总计仍不超过 12 次。耗时检查仍使用原 0.15 秒软时限。

发出的 `TimedTrajectory` 始终从实际输出控制、当前缓存和同一差速动力学重新生成，再执行原有运动、地形及邻居连续检查，不直接发出失配的内部节点。此修正保证**输出轨迹与输出控制的局部模型一致性**，不声称两次迭代能让所有内部 shooting 残差归零，也不等于真实车辆模型误差消失。

### 可行运动前缀

仅对状态 0 或 2、数值有效的求解候选尝试前缀修复：保留候选开头若干控制，后接按原变化率限制生成的减速尾段，末端控制必须为零。完整 3 秒轨迹（包括停车尾段）必须通过原有检查，否则不执行。

前缀最多检查 14 个截断位置，遵守同一墙钟时限；不是 A*、新的路径搜索或固定动作原语，不生成不同任务目标，也不执行未知区域的轨迹。求解器异常、非数值输出、非 0/2 状态或超时仍走原“重新验证旧计划，否则受限减速”链。

新增 `feasible_prefix` 状态及 `prefix_steps`、`candidate_rejection`、`solver_passes`、`model_error_m` 遥测。原候选被拒绝但可行前缀可执行时，不把它混记为完整优化轨迹成功；统计同时保留前缀介入率和原候选拒绝原因。非 0/2 状态改称 `solver_failure`，不冒称严格数学不可行。

### 新鲜停车消息

完整消息可携带停止平移意图：发送方阶段目标速度上限小于 0.05 米/秒、目标尚未过期、实际发布速度小于 0.05 米/秒。只有新鲜完整消息可使用此语义；稀疏消息不能借此缩小预测范围。

对新鲜完整计划，若最后控制区间的平移已经停止，则将终端位置解释为停车尾段，不再因为预测时域比上一计划多出 0.2 秒，就额外添加最大速度外推项。仍保留原 0.42 米名义距离、0.04 米跟踪余量和随消息年龄/预测时间增长的余量。移动尾段保留原最大速度外推；过期消息回到原保守预测，不继续信任停车意图。

这是明确计划/意图假设下的预测修正，不是对任意失联、任意突然加速的无条件安全保证。

## 严格标准

沿用修正前的同批固定目标诊断，不修改到达误差 0.1 米或场景种子。停车对照不能计作运动到达或完整集合成功。生产仍保留碰撞终止及原任务全部判据；本轮没有完整任务学习结果。

冻结探针共48次：原初始化下，cap=0.4和cap=1.15各16个状态全部返回通过完整复查的轨迹（高速14条为前缀）；已知可行热启动组为13条前缀、3条重新验证的旧计划。全部48条发出轨迹再次由输出控制重算的位置误差为0，复查全部通过。

**内部优化差异没有被掩盖**：冻结探针中低速组仍出现最大约0.134米shooting/复算差异，高速原初始化组最大约0.00262米。因此本轮确认的是最终输出/控制一致且安全复查通过，不是所有内部优化状态严格收敛。

开发复测目录 `fix_seed23_extended_v1` 保留；最终结果使用 `*_v2`，不覆盖修正前证据。

## 失败分析与边界

允许接收安全可行的运动前缀，不意味着所有优化均收敛。复杂会车、反复目标切换、稀疏/过期通信和真实动力学下的执行误差仍需进一步完整闭环验证。不因本轮固定目标到达而自动恢复网络训练。
