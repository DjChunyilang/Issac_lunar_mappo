# exp128：奖励分量动作可辨识性诊断

## 目的

exp127 证明联合动作不能稳定改善团队总回报的估计，但尚不能区分两种原因：动作接口整体无效，或关键奖励分量与当前动作没有对齐。exp128 冻结同一策略，直接比较状态模型和状态—联合动作模型对即时加权奖励分量的预测能力。

该实验只读取现有奖励和诊断量，不修改环境奖励、Actor、Critic 或执行链路。

## 方法

奖励按当前实际权重分解：

\[
r_t=
r_t^{\mathrm{gather}}
+r_t^{\mathrm{oracle}}
+r_t^{\mathrm{energy}}
+r_t^{\mathrm{safety}}
+r_t^{\mathrm{terrain}}
+r_t^{\mathrm{flatness}}
+r_t^{\mathrm{motion}}
+r_t^{\mathrm{consistency}}
+r_t^{\mathrm{hold}}
+r_t^{\mathrm{terminal}}.
\]

采集时逐步验证右侧加权和与 `total` 在 (10^{-5}) 容差内相等。两个多输出回归器使用相同的两层 128 单元 ELU 主干、训练样本、模型种子和验证地形种子。对分量 (m) 定义动作增益：

\[
I_m=
\frac{operatorname{MSE}_{s,m}-
\operatorname{MSE}_{s,a,m}}
{\operatorname{MSE}_{s,m}}.
\]

预先规定 `gather`、`safety` 和 `terrain` 三个关键任务分量必须在平均值及每个验证地形种子上同时满足 (I_m\ge0.15)，否则不允许据此改变训练信用。

此外，对四个已有诊断量进行同样分析，但它们不作为环境奖励：相对 quintic 路径风险、预测冲突参与、实际碰撞参与和最近邻距离变化。

## 正式结果

完整覆盖 96 秒 episode：训练 128 个环境，验证每个种子 64 个环境，共使用 61,440 个训练样本和每种子 30,720 个验证样本。

| 分量或诊断量 | 联合动作 MSE 平均改善 | 最差地形种子改善 | 判读 |
| --- | ---: | ---: | --- |
| gather | 50.998% | 49.997% | 动作—集合进度链路清晰 |
| oracle | 36.563% | 35.443% | 仅训练诊断，不进入 Actor |
| safety | 0.099% | 0.025% | 当前安全奖励缺少动作辨识度 |
| terrain | -0.261% | -0.676% | 当前混合地形项缺少动作辨识度 |
| flatness | 6.228% | 5.972% | 未达到门限 |
| total | 0.127% | 0.068% | 总奖励被不可辨识分量主导 |
| 相对 quintic 路径风险 | 0.359% | 0.249% | 固定小网络不能从状态—动作稳定拟合该交互 |
| 预测冲突参与 | 17.557% | 16.671% | 联合动作包含可学习的路径冲突信息 |
| 实际碰撞参与 | 0.156% | 0.101% | 事件过于稀疏且滞后 |
| 最近邻距离变化 | 56.182% | 55.628% | 动作—连续安全变化链路清晰 |

Actor 参数哈希和探针动作均完全不变。

## 结论

exp128 状态为 `stop_reward_credit_candidate`。结果排除了“动作接口整体无效”的解释：集合进度、预测冲突和最近邻变化均具有显著动作增益。当前瓶颈更具体地位于奖励语义：`safety` 将连续近距状态与稀疏碰撞事件混合，`terrain` 将当前地形状态成本与动作相关路径风险混合；两者都未给联合动作模型提供稳定的边际目标。

按预设停止规则，本实验不授权修改训练信用，也不启动新的 4M。下一步只允许进行冻结状态下的配对动作干预，以直接测量单车动作对相对路径风险、预测冲突和最近邻变化的局部响应；在该因果诊断完成前，不增加网络、奖励项或后处理模块。
